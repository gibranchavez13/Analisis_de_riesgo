¿Cómo podemos tener una medida de la volatilidad anual?

dias_cot <- 252

sigma_anual <- sigma_log * sqrt(dias_cot)
sigma_anual
## [1] 0.3248763
sigma_log

Recordemos que \(\sigma^2\) es lineal en el tiempo, sin embargo, \(\sigma\) no lo es, por lo cual para anualizar hay que multiplicar por \(\sqrt{252}\).

\[ \sigma_{anual} = \sigma_{diaria} \sqrt{252} \]

¿Por qué por la raíz del tiempo y no solo por el tiempo?

Porque la varianza incrementa de forma más o menos proporcional al tiempo, pero la desviación estándar no.

Estimar \(\mu\)

Recrodemos que del GBM, tenemos

\[ E[r_{\Delta t}] \approx (\mu_a - \frac{1}{2}\sigma_a^2)\Delta t \]

Si todo está en términos diarios:

\[ \Delta t = \frac{1}{252} \] Despejando:

\[ r_{diaria} \approx (\mu_a - \frac{1}{2}\sigma_a^2) \frac{1}{252} \]

\[ 252r_{diaria} \approx \mu_a - \frac{1}{2}\sigma_a^2 \]

\[ \mu_a \approx 252r_{diaria} + \frac{1}{2}\sigma_a^2 \]

mu_log_anual <- dias_cot * mean_log
mu_log_anual
## [1] 0.132436
mu_gbm_anual <- mu_log_anual + 0.5 * sigma_anual^2

## [1] 0.1852083

¿Por qué sumamos \(\frac{1}{2}\sigma_a^2\)?

Porque cuando tenemos el valor esperado de la distribución en logaritmos restamos ese término a la media y debemos por así decirlo, regresralo.

\[ P(S_T > K) \Rightarrow P(S_T > 200) = P(ln(S_T) > ln(200)) \]

\[ ln(S_T) = ln(S_0) + (\mu - \frac{1}{2}\sigma^2)T + \sigma W_T \]

Para cada uno de estos momentos en el tiempo, debemos obtener el valor esperado, el valor mediano, la moda y un intervalo de confianza digamos al 95%. Todo esto partiendo de lo que conocemos teóricamente.

Para facilitar este cálculo, haremos una función:

Parmámetos: \(S_0\), \(\mu\), \(\sigma\), \(T\), \(\text{Nivel de confianza}\)

gbm_summary <- function(So, mu, sigma, T, nc){
  z_nc = qnorm(1 - (1 - nc) / 2)
  
  c(
    Precio_Esperado = So * exp(mu * T),
    Mediana = So * exp((mu - 0.5 * sigma^2) * T),
    Moda = So * exp((mu - 1.5 * sigma^2) * T),
    
    inferior = So * exp(((mu - 0.5 * sigma^2) * T) - z_nc * sigma * sqrt(T)),
    superior = So * exp(((mu - 0.5 * sigma^2) * T) + z_nc * sigma * sqrt(T))
  )
}

¿Cómo mejoramos la simulación?

Haciendo más simulaciones. Cada simulación, es decir, cada posible valor de S que está en los objetos St_1d, St_1nio, etc., \(\text{corresponde a un posible valor del precio en ese momento}\). NO SE TRATA DE UNA TRAYECTORIA EN EL PRECIO.

Vamos a construir una trauectoria para un año. Usaremos ambas ideas, aproximación con \(d_St\) y la solución exacta:

\[ S_{i+1} = S_i e^{(\mu - \frac{1}{2}\sigma^2) T + \sqrt{T} Z_i} \]

z2 <- rnorm(252)
n_dias <- 252
dt <- 1 / n_dias

S_exacta <- numeric(n_dias+1)
S_aprox <- numeric(n_dias+1)

# Para el precio inicial tomamos So
S_exacta[1] <- So
S_aprox[1] <- So


for (i in 1:n_dias) {
  S_exacta[i+1] <- S_exacta[i] * exp((mu - 0.5 * sigma^2) * dt + sigma * sqrt(dt) * z2[i])
  S_aprox[i+1] <- S_aprox[i] + S_aprox[i] * mu * dt + sigma * S_aprox[i] * sqrt(dt) * z2[i]
}
matplot(
  cbind(
    S_aprox, S_exacta
  ),
  type = 'l',
  xlab = 'Días de cotización',
  ylab = 'Precio',
  main = 'Solución exacta vs. aproximación'
)
